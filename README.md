# Daily Aquarium

Version: 1.0

Daily Aquarium is a gentle Pomodoro-style focus timer. Users enter one small goal, complete a timed focus session, and receive a collectible pixel fish as positive reinforcement.

## Features

- Single-goal focus flow
- Pixel-style welcome, timer, reward, and aquarium screens
- Random fish rewards with non-duplicate priority
- Local aquarium persistence with `localStorage`
- Collectible fish display across small and large tanks

## Project Structure

- `index.html` - app structure and page states
- `style.css` - pixel-style visual system and responsive layout
- `script.js` - timer, reward, aquarium, and storage logic
- `assets/` - fish images, background art, and font assets
- `Daily Aquarium 产品文档（PRD）_副本.md` - product requirements and roadmap

## Run Locally

Open `index.html` in a browser.

## Portfolio Positioning

This project is designed as a calming productivity MVP focused on reduced cognitive load, gentle reinforcement, and progress tracking through a collectible aquarium.
